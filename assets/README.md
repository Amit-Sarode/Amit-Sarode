# Project Demo Assets & GIFs

Store your project screen recordings and demo GIFs here.

### Recommended Tools
- **Windows**: [ScreenToGif](https://www.screentogif.com/) (Free, open-source, built-in frame editor)
- **Mac**: [Kap](https://getkap.co/) (Free, open-source)
- **Linux**: [Peek](https://github.com/phw/peek)
- **Optimizer**: [ezgif.com/optimize](https://ezgif.com/optimize) (Compress GIFs to keep them under 5MB)

### Recommended Filenames
- `mindcare-demo.gif` (5–10s loop of patient intake triage & AI booking)
- `mtms-demo.gif` (5–10s loop of shift rostering & task lifecycles)
- `automation-demo.gif` (5–10s loop of terminal/headless browser run)
- `vibenote-demo.gif` (5–10s loop of audio streaming or mobile UI)

### Linking in `README.md`
Once you drop a GIF in this folder, update the corresponding `src` in `README.md`:
```html
<p align="center">
  <img src="assets/mindcare-demo.gif" alt="MindCare Demo" width="100%" />
</p>
```
